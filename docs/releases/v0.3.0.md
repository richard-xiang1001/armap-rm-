# v0.3.0 — ARMAP-Style Data Construction

Release date: 2026-02-16

## Highlights

- Added ARMAP-style pair builder:
  - `scripts/build_pairs_v030.py`
  - pipeline: `load -> refine_instruction -> negatives -> env_judge -> pair/meta`
- Added instruction refinement module:
  - `ingest/refine_instruction.py` (rule-based, deterministic)
- Added negative generators:
  - `ingest/negatives/replay_corrupt.py`
  - `ingest/negatives/swap_step.py`
  - `ingest/negatives/truncate.py`
  - `ingest/negatives/registry.py`
- Added arithmetic environment judge:
  - `ingest/envs/base.py`
  - `ingest/envs/arithmetic_env.py`

## Schema Extensions (`meta`)

Backward-compatible additions:
- `construction_method`
- `neg_type`
- `replay_ok`
- `replay_attempted`
- `env_judge_pos`
- `env_judge_neg`
- `env_judge_consistent`
- `instruction_refine_mode`
- `instruction_refine_changed`

## Gate Extensions

`scripts/lint_data.py` now reports and can gate on:
- `neg_replay_attempted`
- `neg_replay_ok_count`
- `neg_replay_success_rate`
- `env_judge_consistency`

New gate flags:
- `--fail_on_low_replay_ok --min_replay_ok_rate`
- `--fail_on_low_env_consistency --min_env_judge_consistency`

## Acceptance

Added one-command acceptance:
- `scripts/run_v030_acceptance.py`

Targets include v0.2.1 checks plus:
- `neg_replay_success_rate >= 0.8`
- `env_judge_consistency >= 0.95`
