# v0.1.0 — RM Open-Source Grade Baseline

Release date: 2026-02-16

## Highlights

- End-to-end RM workflow is reproducible on constrained environments:
  - data prep
  - data lint
  - pairwise RM training
  - offline evaluation
- Added dataset linter (`scripts/lint_data.py`) for schema, leakage, and truncation-risk checks.
  - Supports external leak terms (`--leak_terms_file`)
  - Supports step-boundary truncation checks (`truncation_risk_last_k_steps`)
- Added richer eval diagnostics (gap percentiles) without breaking existing parsers.
- Added reproducibility and release metadata docs.

## Known Issues and Mitigations

1. Shared-memory worker failure on restricted macOS/sandbox:
   - Symptom: `torch_shm_manager ... Operation not permitted`
   - Mitigation: run training/eval with `--num_workers 0`

2. Truncation-induced signal loss:
   - Symptom: near-random pair accuracy when `max_len` is too small
   - Root cause: `Final:` line is truncated out of the input window
   - Mitigation: use `max_len=512` for current synthetic data and check `truncation_risk_ratio_final_line` and `truncation_risk_last_k_steps` via `lint_data.py`
