## Commands

### Build Bootstrap Pairs from Online Traces

```bash
python3 scripts/build_v065_bootstrap_pairs.py \
  --traces_path results/v065_bootstrap/round_0/online_traces_merged.jsonl \
  --output_train_jsonl results/v065_bootstrap/round_0/pairs_train.jsonl \
  --output_valid_jsonl results/v065_bootstrap/round_0/pairs_valid.jsonl \
  --pair_policy task_success_then_rm_gap \
  --seed 42 \
  --valid_ratio 0.1 \
  --stats_json results/v065_bootstrap/round_0/pairs_stats.json
```

### Run 2 Bootstrap Rounds

```bash
python3 scripts/run_v065_bootstrap_rounds.py \
  --base_ckpt results/v061_swe_phase1p_r2/pairs_10000/s42_d30/rm.pt \
  --rounds 2 \
  --raw_path data/raw/episodes_swe_v060.jsonl \
  --swe_lite_manifest_path results/v063_swe_real_main/task_manifest_intersection.jsonl \
  --results_dir results/v065_bootstrap \
  --n_tasks 100 \
  --seeds 42,43,44 \
  --bon_n 4 \
  --rollout_horizon 1 \
  --max_env_steps 1
```
