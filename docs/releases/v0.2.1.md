# v0.2.1 — Acceptance Round (5000/500 + CPU/GPU Parity)

Release date: 2026-02-16

## Highlights

- Added one-command acceptance runner:
  - `scripts/run_v021_acceptance.py`
  - covers export/sanitize/lint gate/train/eval/parity checks
- Added exact validation-size split support in pipeline:
  - `scripts/run_v020_pipeline.py --valid_size`

## Acceptance Targets

- Data size target:
  - `train=5000`, `valid=500`
- Gate target:
  - `rows_with_missing=0`
  - `leak_hit_count=0`
  - `truncation_risk_last_k_steps<=0.05`
- Training target:
  - `pair_accuracy>0.55`
  - `gap_p50>0`
- Parity target:
  - `abs(pair_acc_gpu - pair_acc_cpu)<=0.03`

## Canonical Command

```bash
python3 scripts/run_v021_acceptance.py \
  --raw_path data/raw/episodes_real.jsonl \
  --adapter generic_jsonl \
  --work_dir data/real \
  --results_dir results/v021_real \
  --max_pairs 5500 \
  --target_train_size 5000 \
  --target_valid_size 500 \
  --max_len 512 \
  --batch_size 256 \
  --epochs 3 \
  --max_steps 4000 \
  --device cuda \
  --amp_dtype bf16 \
  --num_workers 4
```

Output report:
- `data/real/reports/v021_acceptance.json`
