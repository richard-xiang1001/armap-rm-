# v0.3.2 — Optional Multimodal Scaffold

Release date: 2026-02-16

## Scope

This milestone is optional and does not block v0.3.0/v0.3.1 acceptance.

## Added

- Minimal multimodal RM wrapper:
  - `rm/vlm/wrapper.py`
  - freeze-backbone + train scalar head layout
- Adapter scaffold for Webshop-like trajectories:
  - `ingest/adapters/webshop_like.py`
  - aligns instruction/steps with image paths or URLs in `raw_meta.images`

## Notes

- Default training pipeline remains text-only.
- The multimodal scaffold is intentionally lightweight and ready for replacement with a real VLM encoder.
- If heavy VLM dependencies are unavailable, use caption-to-text as transition strategy.

## Smoke Validation (Webshop-like scaffold)

Validated optional multimodal scaffold path with a synthetic Webshop-like sample:

- input: `data/raw/webshop_like_sample.jsonl` (600 episodes)
- adapter: `webshop_like`
- pair builder: `scripts/build_pairs_v030.py`
- output: `data/webshop_like/pairs.unsanitized.jsonl` (295 pairs)

Observed export stats:
- `episodes_in = 600`
- `success_candidates = 295`
- `pairs_out = 295`
- `neg_type_counts = {"truncate_last_k": 295}`
- `neg_attempted_counts = {"replay_corrupt": 295, "swap_step": 295, "truncate_last_k": 295}`

Interpretation:
- `webshop_like` adapter and v0.3.x pair-construction pipeline run end-to-end without breaking the text-only mainline.
- Current env judge is arithmetic-oriented, so Webshop-like negatives fall back to `truncate_last_k`; this is expected at scaffold stage.
