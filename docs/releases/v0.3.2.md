# v0.3.2 — Optional Multimodal Scaffold

Release date: 2026-02-16

## Scope

This milestone is optional and does not block v0.3.0/v0.3.1 acceptance.

## Added

- Minimal multimodal RM wrapper:
  - `rm/vlm/wrapper.py`
  - freeze-backbone + train scalar head layout
- Adapter scaffold for Webshop-like trajectories:
  - `ingest/adapters/webshop_like.py`
  - aligns instruction/steps with image paths or URLs in `raw_meta.images`

## Notes

- Default training pipeline remains text-only.
- The multimodal scaffold is intentionally lightweight and ready for replacement with a real VLM encoder.
- If heavy VLM dependencies are unavailable, use caption-to-text as transition strategy.
