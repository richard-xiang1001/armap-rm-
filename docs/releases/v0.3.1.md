# v0.3.1 — Trajectory Input Shape + Pooling Ablations

Release date: 2026-02-16

## Highlights

- Added structured step formatter:
  - `rm/formatters/stepwise.py`
  - step tags: `<OBS>...</OBS>`, `<ACT>...</ACT>`, `<RES>...</RES>`
- Added configurable pooling:
  - `rm/pooling.py`
  - `mean`, `last`, `last_k_step`
- Extended training/eval CLI:
  - `--input_format {flat,stepwise}`
  - `--pooling {mean,last,last_k_step}`
  - `--last_k_steps_pool`
  - `--use_refined_instruction {true,false}`

## Model/Checkpoint Compatibility

- Existing v0.2.x checkpoints still load.
- New checkpoints store:
  - `pooling`
  - `last_k_steps_pool`
  - `input_format`
  - `use_refined_instruction`

## Expected Validation Pattern

- `pair_accuracy` should not regress materially versus v0.3.0 baseline.
- `gap_p50` stability and truncation robustness (`max_len 512 -> 384`) should be evaluated via ablations.
