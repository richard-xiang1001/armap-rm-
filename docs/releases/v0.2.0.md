# v0.2.0 — 4090 Lightweight Training + Real-Trajectory Ingest

Release date: 2026-02-16

## Highlights

- Added a full real-trajectory data path:
  - episode JSONL ingest adapters (`generic_jsonl`, `armap_style`)
  - pair export (`ingest/export_pairs.py`)
  - sanitize/audit layer (`ingest/sanitize_traj.py`)
- Added strict training gate before RM fitting:
  - missing required fields must be zero
  - leak hits must be zero
  - `truncation_risk_last_k_steps <= 0.05`
- Upgraded RM training CLI for 4090-style throughput tuning:
  - explicit `--device`
  - AMP control (`--amp_dtype`)
  - gradient accumulation (`--grad_accum_steps`)
  - capped smoke runs (`--max_steps`)
  - DataLoader knobs (`pin_memory/prefetch_factor/persistent_workers`)
- Added end-to-end runner:
  - `scripts/run_v020_pipeline.py`
  - fixed order: `export_pairs -> sanitize -> lint gate -> train -> eval`

## Acceptance Targets

- GPU smoke (200 steps):
  - `pair_accuracy > 0.55`
  - throughput (`samples_per_sec`) higher than CPU baseline
- CPU/GPU parity:
  - same seed + same validation set
  - `abs(pair_acc_gpu - pair_acc_cpu) <= 0.03`
- Eval output compatibility:
  - existing keys retained (`pair_accuracy`, `avg_reward_gap`, `n`)
  - percentile keys retained (`gap_p10`, `gap_p50`, `gap_p90`)

## Example Commands

```bash
python3 scripts/generate_real_episode_sample.py --out_path data/raw/example_episodes.jsonl

python3 scripts/run_v020_pipeline.py \
  --raw_path data/raw/example_episodes.jsonl \
  --adapter generic_jsonl \
  --work_dir data/real \
  --results_dir results/v020_real \
  --max_len 512 \
  --batch_size 128 \
  --epochs 2 \
  --max_steps 200 \
  --device auto \
  --amp_dtype bf16
```

## Known Constraints

- If CUDA wheels cannot be fetched from network-restricted hosts, install from local wheels:
  - `pip install --no-index --find-links wheels -r requirements.txt`
- In restricted macOS/sandbox environments, use `--num_workers 0`.
